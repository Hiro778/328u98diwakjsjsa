Perbaiki quantity selector pada Public Product Detail.

Current UI:
[ − ] [ 109 ] [ + ]

Problem:
Quantity sekarang terasa seperti hanya bisa dinaikkan/diturunkan lewat tombol +/−. User harus menekan + berkali-kali untuk jumlah besar.

Requirement:
1. Jadikan angka quantity di tengah sebagai INPUT yang bisa diketik langsung.
2. User harus bisa:
   - klik angka quantity
   - Ctrl+A
   - ketik jumlah baru, misalnya 250
   - Enter / blur untuk menerapkan.
3. Tombol − dan + tetap tersedia dan tetap berfungsi.
4. Validasi:
   - minimum = 1
   - maksimum = stok tersedia / max quantity yang saat ini digunakan aplikasi
   - input kosong jangan menyebabkan NaN atau state rusak
   - karakter non-numerik tidak boleh menghasilkan quantity invalid
5. Jangan mengubah behavior:
   - subtotal
   - Add to Cart
   - Beli Langsung
   - stock validation
   - cart persistence
6. Saat user mengetik quantity yang valid, subtotal harus langsung mengikuti quantity tersebut.
7. Saat quantity melebihi stok, clamp/tolak sesuai behavior existing aplikasi; jangan bypass stock limit.
8. Pertahankan styling UI sekarang supaya input tetap terlihat seperti angka quantity di tengah selector.
9. Support keyboard:
   - Enter → commit quantity
   - Arrow Up/Down boleh digunakan jika mudah, tetapi bukan requirement wajib.
10. Jangan ubah database atau schema.
11. Jangan ubah QRIS/POS/payment/subscription/admin/maintenance.

Test:
- quantity 1 → ketik 109
- ketik 250 langsung
- ketik 0
- ketik angka > stok
- input kosong
- ketik huruf
- klik +/− setelah mengetik manual
- pastikan subtotal benar
- pastikan Add to Cart dan Beli Langsung menggunakan quantity terakhir.

Run relevant tests + npm run build.

- validation min/max
- test result
- build result
