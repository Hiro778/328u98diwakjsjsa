Tambahkan Pie Chart/Doughnut Chart ke sheet "Ringkasan" pada laporan Excel penjualan.

Requirement:
1. Jangan menghapus atau mengubah tabel laporan yang sudah ada.
2. Pertahankan tabel "LAPORAN PENJUALAN HARIAN - SEPTEMBER 2026" seperti sekarang.
3. Tambahkan 1 Doughnut/Pie Chart di sebelah kanan tabel, mulai sekitar kolom I/J agar tidak menutupi tabel.
4. Chart harus mengambil data secara dinamis dari data penjualan yang menjadi sumber laporan.
5. Chart menampilkan komposisi penjualan berdasarkan PRODUK TERJUAL.
6. Jika belum ada transaksi/data produk:
   - chart tetap valid
   - jangan menghasilkan error atau data palsu
   - tampilkan kondisi kosong/placeholder yang sesuai.
7. Chart harus ikut berubah otomatis ketika data penjualan berubah atau laporan di-generate ulang.
8. Beri judul:
   "Komposisi Penjualan Produk"
9. Gunakan legend/nama produk yang jelas.
10. Jangan menggunakan Data Bars/Conditional Formatting sebagai pengganti chart. Ini harus benar-benar Excel Pie/Doughnut Chart.
11. Letakkan chart di area kanan tabel dan pastikan tidak overlap dengan tabel.
12. Jangan mengubah formula revenue, transaksi, kerugian, atau data sumber lainnya.
13. Jika workbook generator/export Excel sudah punya fungsi khusus untuk membuat sheet Ringkasan, integrasikan chart di sana agar setiap export menghasilkan chart tersebut.

Setelah selesai:
- test generate/export Excel
- buka/validasi workbook hasil
- pastikan sheet Ringkasan memiliki tabel + Pie/Doughnut Chart di sebelah kanan
- pastikan tidak ada chart duplikat ketika file dibuat ulang
- jalankan test yang relevan.
